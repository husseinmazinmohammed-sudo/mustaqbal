# تطوير مستعرض الأدلة الرسمي لجامعة المستقبل ونظام إشعارات Gmail وتحديث الواجهة المكتبية

تهدف هذه التحديثات إلى إعادة تصميم مستعرض الأدلة الاسترشادية ليعمل كوثيقة هندسية أكاديمية وسريرية عالية التنظيم، وتوفير نظام طباعة وتصدير PDF رسمي معتمد باسم **جامعة المستقبل (الجامعة الأهلية الأولى في العراق) - كلية التقنيات الهندسية - قسم هندسة تقنيات الأجهزة الطبية**، بالإضافة إلى ربط حساب Google الرسمي عبر **Gmail API** لإرسال إشعارات حجز الاستشارات مباشرة إلى `hassinmazin301@gmail.com` مع ترقية شاملة لحداثة التصميم المكتبي.

### User Review & Critical Decisions

> [!IMPORTANT]
> **القرارات المعتمدة من قبلك قبل التنفيذ:**
> - **الترويسة الأكاديمية الرسمية للـ PDF والمنصة**: اعتماد الهوية الرسمية لـ **جامعة المستقبل (Al-Mustaqbal University) - الجامعة الأهلية الأولى في العراق / كلية التقنيات الهندسية / قسم هندسة تقنيات الأجهزة الطبية** في ترويسة وتذييل جميع الأدلة المطبوعة وبطاقات التوثيق.
> - **إشعارات البريد الإلكتروني عبر Gmail API**: ربط حساب Google الرسمي باستخدام صلاحية الإرسال (`gmail.send`) لإرسال تفاصيل كل حجز استشارة فور تأكيد المستخدم إلى البريد `hassinmazin301@gmail.com`، مع نافذة تأكيد صريحة قبل الإرسال وبديل فوري في حال عدم تسجيل الدخول.
> - **تصميم مكتبي حديث وموحد**: توحيد جميع النوافذ المنبثقة والمستعرضات على النمط السريري الفاتح المهدئ للعين وإلغاء أي تعارض مع الوضع الداكن للمتصفح أو المحارف النصية المتكسرة.

### 1. Overview & Core Concept

- **What It Does**:
  1. **مستعرض أدلة هندسية احترافي ومرتب (Structured Desktop Document Viewer)**: نافذة مكتبية عريضة مقسمة إلى ترويسة أكاديمية رسمية، ملخص تنفيذي منظم، جدول معايير قياسي، ومصفوفة خطوات بروتوكول مرقمة بوضوح مع نقاط التدقيق الحرجة.
  2. **محرك طباعة وتصدير PDF رسمي لجامعة المستقبل (Official A4 Print & PDF Engine)**: عند الضغط على زر الطباعة أو تصدير الـ PDF، يتم عرض وتوليد مستند رسمي مقاس A4 يتضمن شعار وترويسة جامعة المستقبل (باللغتين العربية والإنجليزية)، اسم الكلية والقسم، جداول المعايير الهندسية، ختم الاعتماد الأكاديمي، وتوقيع وحدة السلامة وهندسة الأجهزة الطبية، مع إخفاء كافة عناصر الموقع الأخرى أثناء الطباعة (`@media print`).
  3. **نظام إشعارات Gmail الرسمي للحجوزات**: إرسال بريد إلكتروني منسق رسمياً بتفاصيل تذكرة الاستشارة (اسم المستفيد، القسم، المحور، التاريخ، الوقت، درجة الأولوية، والملاحظات) إلى `hassinmazin301@gmail.com` عبر Gmail API بعد موافقة المستخدم الصريحة.
- **Target Audience / Persona**: مهندسو تقنيات الأجهزة الطبية، تدريسيو وطلبة كلية التقنيات الهندسية في جامعة المستقبل، الكوادر الصحية، وزوار المنشآت الطبية.
- **Key Value**: تحويل الأدلة من نصوص عادية إلى وثائق أكاديمية وسريرية رسمية جاهزة للطباعة والتوزيع الميداني، مع أتمتة إشعارات الاستشارات الهندسية عبر البريد الرسمي.

### 2. User Experience & Visual Design

- **Key User Flows**:
  1. **تصفح الدليل وطباعته كـ PDF رسمي**:
     - يضغط المستخدم على **"تصفح الدليل الشامل"** أو **"بطاقة الجيب للطباعة"**.
     - تفتح نافذة مكتبية فسيحة ومنظمة تعرض الترويسة الرسمية لجامعة المستقبل (كلية التقنيات الهندسية - قسم هندسة تقنيات الأجهزة الطبية)، متبوعة ببطاقات المعايير الدولية، وجدول الخطوات الميدانية، وجدول الحدود القياسية المنسق (بدون رموز ASCII المتكسرة).
     - عند الضغط على **"طباعة / حفظ كملف PDF رسمي"**، يتم تفعيل قالب الطباعة الأكاديمي المخصص A4 ليحفظه المتصفح كملف PDF رسمي متكامل.
  2. **حجز استشارة وإرسال إشعار Gmail**:
     - يملأ الزائر أو المهندس نموذج حجز الاستشارة ويضغط **"تأكيد الحجز وإرسال الإشعار"**.
     - تظهر نافذة تأكيد واضحة تستعرض تفاصيل الرسالة الموجهة إلى `hassinmazin301@gmail.com`.
     - إذا كان المستخدم مسجلاً دخوله بحساب Google، يتم إرسال البريد مباشرة عبر Gmail API وعرض حالة الإرسال المؤكدة؛ وإذا لم يكن مسجلاً، يُعرض زر **"تسجيل الدخول بحساب Google"** الرسمي إلى جانب خيار الإرسال البريدي المباشر.
- **Visual Identity & Theme**:
  - *Aesthetic Direction*: تصميم مؤسسي أكاديمي وسريري فائق الحداثة (Modern Academic & Clinical Precision) يجمع بين الهوية الرسمية لجامعة المستقبل والوضوح الهندسي.
  - *Color Palette & Mood*: خلفية رخامية فاتحة (`#F8FAF9`)، أسطح بطاقات بيضاء نقية (`#FFFFFF`)، حدود دقيقة (`#E2E8F0`)، وتدرجات التيل الطبي والأخضر الزمردي الأكاديمي (`#0F766E`, `#0D9488`) مع لمسات ذهبية أكاديمية هادئة (`#B45309`) لختم الجامعة.
  - *Typography & Hierarchy*: خط `IBM Plex Sans Arabic` بوزن `300` للنصوص الشارحة، ووزن `600` للعناوين والترويسات الرسمية، مع خط `JetBrains Mono` للأكواد الهندسية وأرقام التذاكر.
  - *Component Styling & Layout*: نوافذ مكتبية عريضة (`max-w-4xl`) ذات تقسيم شبكي ثنائي الأعمدة، وجداول HTML حقيقية منظمة تحل محل النصوص المسبقة التنسيق (`pre`).

### 3. Key Product Decisions & Trade-Offs

- **Decision 1: استبدال ملخصات ASCII بجداول ومكونات رسمية مع قالب طباعة `@media print` مخصص**
  - *Chosen Approach*: بناء مكون وثيقة رسمية متكامل يحتوي على جداول منظمة وترويسة جامعة المستقبل، مع تخصيص قواعد طباعة CSS تحول الصفحة عند أمر الطباعة إلى مستند A4 رسمي خالٍ من أزرار التحكّم والخلفيات الداكنة.
  - *Why*: الرسوم النصية (`┌──┐`) تتكسر في الاتجاه من اليمين إلى اليسار (RTL) وتظهر بشكل غير مرتب، بينما الجداول الأصلية مع قالب الطباعة المخصص تنتج ملف PDF رسمي وأنيق.
- **Decision 2: تكامل Gmail API مع نافذة تأكيد إلزامية**
  - *Chosen Approach*: استخدام مصادقة Google في المتصفح مع نطاق `https://www.googleapis.com/auth/gmail.send` وتخزين رمز الوصول في الذاكرة المؤقتة فقط، مع عرض نافذة تأكيد للمستخدم قبل إرسال البريد إلى `hassinmazin301@gmail.com`.
  - *Why*: يضمن الأمان والامتثال لمعايير Google Workspace ويتيح إرسال إشعارات حقيقية وموثقة من داخل التطبيق.
